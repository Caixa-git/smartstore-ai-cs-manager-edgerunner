## Cycle 02 변경 사항

### 1. 검색어 입력 (Search)
- **위치:** 히어로 섹션과 하이라이트 사이, 돋보기 아이콘 포함 입력창
- **대상:** 고객 라벨 / 상품명 / 문의 메시지 / AI 요약 / 답변 초안 (5개 필드)
- **동작:** 250ms 디바운스 실시간 검색 + Enter 키 검색
- **초기화:** × 버튼으로 검색어 즉시 삭제
- **결과:** "N개 검색 결과" 표시, 검색 결과 0건 시 맞춤 빈 상태 메시지

### 2. 정렬 기능 (Sort)
- **4종 모드:** 최신순 / 우선순위 높은순 / 위험도 높은순 / 사장님 확인 필요 우선
- **UI:** 필터 아래 teal 색상 정렬 버튼 그룹
- **조합:** 검색 + 필터 + 정렬 동시 적용 가능

### 3. 위험도 서브 필터 (Risk Sub-Filter)
- **5단계:** 전체 위험 / 치명(critical) / 높음(high) / 보통(medium) / 낮음(low)
- **UI:** 정렬 아래 red 계열 위험도 버튼 그룹
- **카드 배지:** 각 문의 카드에 위험도 레벨 배지 표시 (치명=진한빨강/높음=빨강/보통=노랑/낮음=초록)
- **데이터 정확성 확인:** critical=1건(INQ-018), high=3건(INQ-007/008/027), medium=4건

### 4. 모바일 480px 이하 최적화
- 검색 입력창 full-width + 16px 폰트
- 정렬/위험도/필터 버튼 최소 44px 터치 타겟
- 모달 하단 시트 스타일 (상단 둥글게, 하단 고정)
- 통계 세로 정렬
- 모든 UI 요소 사용 가능 상태 유지

### 5. 초기화 버튼 강화
- 시각적: 🔄 아이콘 + primary 배경 + 둥근 필 버튼
- 상태: 호버 시 그림자 + 상승 효과, active 시 눌림 효과
- 동작: 검색어 + 필터 + 정렬 + 위험도 필터 전체 초기화 + 대시보드로 스크롤
